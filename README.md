# Хакатон "Прогноз цены ПВХ"

## Структура проекта
- `data/raw/` — исходные файлы (не в Git)
- `data/processed/` — очищенные данные и признаки
- `notebooks/` — Jupyter ноутбуки для EDA и экспериментов
- `src/` — production-скрипты (загрузка, фичи, обучение)
- `submissions/` — файлы для сдачи (forecast.csv, strategy.csv)
- `models/` — сохраненные веса моделей

## Установка
1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python3 -m venv venv`
3. Активируйте: `source venv/bin/activate`
4. Установите зависимости: `pip install -r requirements.txt`

## Как запустить
1. Положите исходный файл в `data/raw/`.
2. Запустите загрузку: `python src/load_data.py`
3. (Дальнейшие шаги будут добавлены)
